# 丁达尔效应的现象
**丁达尔效应**（Tyndall Effect）通常指光束通过胶体等分散体系时，从侧面可以观察到明亮光路的现象。

观察的起点是一个问题：光沿着照射方向传播，站在光束侧面的人为什么也能看见这段光路？关键在于有一部分光改变了传播方向，从介质内部到达观察者眼睛。[[分散系]]中的粒子提供了这种散射。

e.g. 阳光穿过有细尘的空气、光束穿过适当浓度的胶体时，散射可以使光路变得可见。粒子本身的分布和光照条件共同决定观察结果。
# 光散射的解释
入射光的电场使物质中的电荷响应，并向其他方向辐射，形成散射光。分散粒子与周围介质的光学性质存在差异时，可能产生比均匀介质背景更显著的散射，使整段光路显现。

当粒子远小于光的波长，且满足相应模型条件时，可用瑞利散射近似解释：保持粒子性质和其他条件相同，短波光通常比长波光更容易散射。粒径接近波长时，散射的强度及角分布更复杂，需要米氏散射等模型。

因此，“能否看到光路”取决于粒径、粒子数、折射率差异、入射光强和观察角度。过浓的体系还可出现多次散射，使背景浑浊，反而难以辨认一条清楚的光路。
# 与溶液和胶体的关系
常见真[[溶液]]中的分子、离子也会散射光，只是普通课堂条件下，侧向散射通常较弱。适当[[胶体]]中的散射较容易观察，因此丁达尔现象常被用来辅助区分常见溶液与胶体。

这一检验是有条件的观察证据。未看见光路，可能是浓度、折射率差异或照明不足；看见光路，也可能来自尘埃、气泡或较粗颗粒。要判断体系类别，应同时核对组成、制备方式、粒径及稳定性。

原来从化学分类继续追问其物理本质的方向，在这里自然连通了两种视角：胶体研究粒子如何分散，光学研究这些粒子如何改变光的传播。
