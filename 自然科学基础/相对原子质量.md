# 相对原子质量的定义
相对原子质量 (Relative Atomic Mass)是一种表示原子质量的方式，符号为 $A_{r}$，是元素的平均原子质量与原子质量单位 (u) 的比值，因此，相对原子质量是一个纯数，没有单位。
## 原子质量单位
原子质量单位（amu 或 u），是用来衡量原子或分子质量的单位。国际上通常采用一个原子的质量单位为基准，定义碳12原子质量的 $\frac{1}{12}$ 为一个原子质量单位。

# 相对原子质量的测量
相对原子质量≈质子数+中子数（即质量数），或 $\frac{一个该原子的实际质量}{1.6606\times 10^{-27}}$。
