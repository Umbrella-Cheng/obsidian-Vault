#常见离子反应 #化学 #备考

本清单用于快速判断高中常见物质是否反应、反应后产生什么现象，以及如何检验离子。默认讨论水溶液；温度、酸碱性、试剂用量等条件另行注明。检验时须考虑干扰离子，不能只凭一种相似现象下结论。

## 沉淀生成

- [ ] $\ce{Ag+ + Cl- -> AgCl v}$：白色沉淀，难溶于稀硝酸。常用酸化的 $\ce{AgNO_{3}}$ 溶液检验 $\ce{Cl-}$ 离子
- [ ] $\ce{Ag+ + Br- -> AgBr v}$：淡黄色沉淀。
- [ ] $\ce{Ag+ + I- -> AgI v}$：黄色沉淀。
- [ ] $\ce{Ba^{2+} + SO4^{2-} -> BaSO4 v}$：白色沉淀，难溶于稀盐酸。
- [ ] $\ce{Ba^{2+} + CO3^{2-} -> BaCO3 v}$：白色沉淀，遇酸溶解并释放二氧化碳。
- [ ] $\ce{Ca^{2+} + CO3^{2-} -> CaCO3 v}$：白色沉淀。
- [ ] $\ce{Mg^{2+} + 2OH- -> Mg(OH)2 v}$：白色沉淀。
- [ ] $\ce{Cu^{2+} + 2OH- -> Cu(OH)2 v}$：蓝色沉淀。
- [ ] $\ce{Fe^{2+} + 2OH- -> Fe(OH)2 v}$：白色沉淀，暴露在空气中易逐渐变为灰绿色、红褐色。
- [ ] $\ce{Fe^{3+} + 3OH- -> Fe(OH)3 v}$：红褐色沉淀。
- [ ] $\ce{Al^{3+} + 3OH- -> Al(OH)3 v}$：白色胶状沉淀。
- [ ] $\ce{Cu^{2+} + S^{2-} -> CuS v}$：黑色沉淀；硫化物沉淀还受酸碱性影响。

## 酸与弱酸根、气体生成

- [ ] $\ce{CO3^{2-} + H+ -> HCO3-}$：酸不足时可先生成碳酸氢根。
- [ ] $\ce{HCO3- + H+ -> CO2 ^ + H2O}$：产生二氧化碳。
- [ ] $\ce{SO3^{2-} + 2H+ -> SO2 ^ + H2O}$：酸化产生二氧化硫。
- [ ] $\ce{S^{2-} + 2H+ -> H2S ^}$：酸化可能产生有毒硫化氢。
- [ ] $\ce{NH4+ + OH- -> NH3 ^ + H2O}$：强碱、加热促进氨气逸出。
- [ ] $\ce{CH3COO- + H+ <=> CH3COOH}$：生成弱酸，通常无明显肉眼现象。
- [ ] $\ce{HCO3- + OH- -> CO3^{2-} + H2O}$：碳酸氢根与强碱反应。
- [ ] $\ce{HSO3- + OH- -> SO3^{2-} + H2O}$：亚硫酸氢根与强碱反应。

## 氧化还原：容易漏判的反应

- [ ] $\ce{2Fe^{3+} + Fe -> 3Fe^{2+}}$：三价铁氧化单质铁。
- [ ] $\ce{2Fe^{3+} + Cu -> 2Fe^{2+} + Cu^{2+}}$：三价铁可溶解铜。
- [ ] $\ce{2Fe^{3+} + 2I- -> 2Fe^{2+} + I2}$：三价铁氧化碘离子。
- [ ] $\ce{2Fe^{2+} + Cl2 -> 2Fe^{3+} + 2Cl-}$：氯气氧化亚铁离子。
- [ ] $\ce{Cl2 + 2Br- -> 2Cl- + Br2}$：氯气氧化溴离子。
- [ ] $\ce{Cl2 + 2I- -> 2Cl- + I2}$：氯气氧化碘离子。
- [ ] $\ce{Br2 + 2I- -> 2Br- + I2}$：溴氧化碘离子。
- [ ] $\ce{MnO4- + 5Fe^{2+} + 8H+ -> Mn^{2+} + 5Fe^{3+} + 4H2O}$：酸性高锰酸根氧化亚铁离子。
- [ ] $\ce{2MnO4- + 5H2O2 + 6H+ -> 2Mn^{2+} + 5O2 ^ + 8H2O}$：酸性条件下过氧化氢表现还原性。
- [ ] $\ce{H2O2 + 2I- + 2H+ -> I2 + 2H2O}$：酸性条件下过氧化氢表现氧化性。
- [ ] $\ce{SO2 + Br2 + 2H2O -> SO4^{2-} + 2Br- + 4H+}$：溴水褪色，体现二氧化硫的还原性。
- [ ] $\ce{SO2 + Cl2 + 2H2O -> SO4^{2-} + 2Cl- + 4H+}$：二氧化硫与氯气在水中发生氧化还原反应。
- [ ] $\ce{Cl2 + 2OH- -> Cl- + ClO- + H2O}$：冷的稀碱溶液中，氯气歧化；条件改变产物可能不同。
- [ ] $\ce{2Fe^{3+} + SO3^{2-} + H2O -> 2Fe^{2+} + SO4^{2-} + 2H+}$：亚硫酸根可还原三价铁。

## 配位、显色与特殊反应

- [ ] $\ce{Fe^{3+} + SCN- <=> [FeSCN]^{2+}}$：血红色；为高中常用的简化配位表示。
- [ ] $\ce{Cu(OH)2 + 4NH3 <=> [Cu(NH3)4]^{2+} + 2OH-}$：足量氨水使氢氧化铜沉淀溶解，出现深蓝色溶液。
- [ ] $\ce{AgCl + 2NH3 <=> [Ag(NH3)2]+ + Cl-}$：氯化银可溶于足量氨水。
- [ ] 碘与淀粉：形成蓝色显色体系，常用于检验碘。
- [ ] 苯酚与三价铁盐溶液：通常显紫色，用于酚羟基的定性检验。
- [ ] $\ce{Fe^{2+}}$ 的检验可采用先加 KSCN 无明显血红色、再适量氧化后出现血红色的思路；必须排除原有 $\ce{Fe^{3+}}$ 和其他干扰。

## 少量、过量与两性反应

- [ ] $\ce{Al^{3+} + 3OH- -> Al(OH)3 v}$：加入适量强碱，先产生白色沉淀。
- [ ] $\ce{Al(OH)3 + OH- -> [Al(OH)4]-}$：强碱过量，沉淀溶解。
- [ ] $\ce{Al(OH)3 + 3H+ -> Al^{3+} + 3H2O}$：氢氧化铝溶于酸。
- [ ] $\ce{Al^{3+} + 3NH3*H2O -> Al(OH)3 v + 3NH4+}$：加氨水产生沉淀，过量氨水通常不能使其溶解。
- [ ] $\ce{Ca^{2+} + 2OH- + CO2 -> CaCO3 v + H2O}$：澄清石灰水通入适量二氧化碳变浑浊。
- [ ] $\ce{CaCO3 + CO2 + H2O -> Ca^{2+} + 2HCO3-}$：继续通入过量二氧化碳，沉淀可溶解。
- [ ] $\ce{CO2 + 2OH- -> CO3^{2-} + H2O}$：碱相对过量时主要形成碳酸根。
- [ ] $\ce{CO2 + OH- -> HCO3-}$：二氧化碳相对过量时主要形成碳酸氢根。
- [ ] $\ce{Ca^{2+} + HCO3- + OH- -> CaCO3 v + H2O}$：碳酸氢钠过量、氢氧化钙不足时的净离子方程式。
- [ ] $\ce{Ca^{2+} + 2HCO3- + 2OH- -> CaCO3 v + CO3^{2-} + 2H2O}$：氢氧化钙过量、碳酸氢根不足时的净离子方程式。

## 离子检验速查

- [ ] **氯离子**：稀硝酸酸化，再加硝酸银，出现白色 $\ce{AgCl}$ 沉淀。
- [ ] **溴离子**：稀硝酸酸化，再加硝酸银，出现淡黄色 $\ce{AgBr}$ 沉淀。
- [ ] **碘离子**：硝酸银生成黄色 $\ce{AgI}$ 沉淀；氧化后可借助淀粉显色，但须排除干扰。
- [ ] **硫酸根**：先加稀盐酸排除部分干扰，再加氯化钡，产生白色 $\ce{BaSO4}$ 沉淀；仍需考虑特殊干扰。
- [ ] **碳酸根或碳酸氢根**：酸化产生二氧化碳，可使澄清石灰水变浑浊；亚硫酸根等可能干扰。
- [ ] **铵根**：与强碱共热，逸出的氨气使湿润红色石蕊试纸变蓝。
- [ ] **三价铁离子**：加 KSCN 溶液呈血红色。
- [ ] **亚铁离子**：加 NaOH 可产生易氧化变色的沉淀；也可结合 KSCN 和适当氧化步骤辨认。
- [ ] **铜离子**：加 NaOH 产生蓝色沉淀；加过量氨水可形成深蓝色配合物。
- [ ] **铝离子**：加 NaOH 先沉淀、后在过量强碱中溶解；此现象不是绝对专一。
- [ ] **钙离子**：可与草酸根形成白色草酸钙沉淀；需排除其他可沉淀的金属离子。

## 判断反应时逐项排查

- [ ] 先写出溶液中实际存在的主要粒子，识别弱电解质、难溶物和配合物。
- [ ] 检查能否生成沉淀、气体或弱电解质。
- [ ] 检查是否发生酸碱反应，尤其关注 $\ce{HCO3-}$、$\ce{HSO3-}$、$\ce{NH4+}$。
- [ ] 检查是否存在氧化剂与还原剂，结合介质和反应条件判断能否发生氧化还原。
- [ ] 检查是否发生配位或特殊显色。
- [ ] 对两性物质和多元弱酸体系，区分少量与过量。
- [ ] 写离子方程式后，核对原子守恒、电荷守恒、物态和反应条件。
- [ ] 做检验题时，区分“观察到某现象”与“足以唯一确认某离子”，逐一排除干扰。

> [!note] 重点辨析
> $\ce{Fe^{3+}}$ 遇 $\ce{I-}$ 主要考虑氧化还原，遇 $\ce{SCN-}$ 主要考虑配位显色；$\ce{Al^{3+}}$ 遇少量、过量强碱会有不同结果。判断反应不能只看离子电荷，也不能只靠复分解反应的三个常见条件。
