# 计算相对分子质量
将化学式中各元素的相对原子质量，乘以该元素的原子个数，然后将乘积相加。
假设存在化学式 $A_{m}B_{n}$，$M_{r}=A_{r}(A)\times m+Ar(B)\times n$。
# 计算物质组成的元素质量比
化合物中，各元素的质量比等于各元素的相对原子质量与对应元素原子个数的乘积比。
将化学式中各元素的相对原子质量，乘以该元素的原子个数，然后将得到的乘积相比化简。
即 $A_{r}(A)\times m:A_{r}(B)\times n$
# 计算物质中某元素的质量分数
化合物中某元素的质量分数= $\frac{该元素的相对原子质量\times 化学式中该原子个数}{该物质的相对分子质量}\times 100\%$
即 $\frac{A_{r(A)\times m}}{M_{r(A_{m}B_{n})}}\times 100\%$.

# 有关化学反应中杂质问题的计算
化学方程式所表示的都是纯净物之间的化学反应，根据其化学式计算的相对分子质量反映的是纯净物之间的质量关系。而在实际生产中，原料和产品都不可能是纯净物，因此在计算中必须根据纯度求出样品中纯净屋质量。

混合物中某物质的质量分数= $\frac{该纯净物的质量}{混合物的总质量}\times 100\%=1-杂质的质量分数$
某纯净物质的质量= 不纯物质的总质量 $\times$ 该物质的质量分数
不纯物质的总质量= $\frac{某物质的质量}{某物质的质量分数}$

含杂质问题的计算，一般都假定杂质不参与反应。
## 化学反应中有关杂质问题的计算步骤
1. 根据纯度，求出样品中纯净物质量。
2. 将纯物质的质量代入化学方程式进行计算。
3. 将计算得到的纯物质的质量换算成含杂质物质的质量。
e.g
某石灰石样品，其中碳酸钙占80%，其余20%是杂质。需要多少吨含 80% $CaCO_{3}$ 的石灰石才能制得100吨氧化钙？
样品质量=100g
纯 $CaCO_{3}$ 质量= $100\times 80\%=80g$
因为 $\ce{CaCO_{3}->CaO +CO_{2}}$
所以100g $CaCO_{3}$ =56g $CaO$
设需要 x 吨纯 $CaCO_{3}$
则 $\frac{x}{100}=\frac{100}{56}$
$x≈178.6$
因为纯度80%，所以每100t 石灰石里只有80t $CaCO_{3}$
所以 $\frac{178.6}{80\%}=223.25$
# 溶液浓度（质量分数）的计算
$溶液的质量分数= \frac{溶质质量}{溶液质量}\times 100\%=\frac{溶质质量}{溶质质量+溶剂质量}\times 100\%$
$溶质质量=溶液质量\times 溶质的质量分数$
$溶液质量=\frac{溶质质量}{溶质的质量分数}$

# 溶液稀释关系式
计算依据：稀释前后溶液中溶解掉了的溶质不变。
## 加水稀释
$A·a\%=B·b\%$ 
或
$A·a\%=(A+m_{水})·b\%$
其中 $B=A+m_{水}$（A 代表浓溶液质量，a%是浓溶液的溶质质量分数；B 代表稀释后的溶液质量，b%代表稀释后溶液的溶质质量分数。$m_{水}$ 代表加入水的质量）
## 加入低浓度溶液稀释
$A·a\%+B·b\%=(A+B)·c\%$（c%代表混合后所得的溶液的溶质质量分数）

# 溶液增浓关系式
## 加溶质
$A\times a\%+B=(A+B)\times c\%$（A 表示原溶液的质量，a%表示原溶液的溶质质量分数，B 表示加入的溶质质量，c%表示加入溶质后所得溶液的溶质质量分数）
计算依据：增加溶质后，溶液中溶质的质量等于原溶液中溶质的质量+增加的溶质的质量。
## 蒸发溶剂
$A\times a\%=(A-B)\times c\%$（A 表示原溶液的质量，a%表示原溶液的溶质质量分数，B 表示蒸发的溶剂质量，c%表示蒸发溶剂后所得溶液的溶质质量分数）
计算依据：蒸发溶剂前后，溶质的质量不变。
## 与同种溶质的浓溶液混合
$A\times a\%+B\times b\%=(A+B)\times c\%$（A 表示原溶液的质量，a%表示原溶液的溶质质量分数，B 表示浓溶液质量，b%表示浓溶液中溶质的质量分数，c%表示混合后所得溶液的溶质质量分数）
计算依据：混合后溶液的总质量等于两溶液的致良知和，混合后的溶液中溶质质量等于两溶液的溶质质量之和。
