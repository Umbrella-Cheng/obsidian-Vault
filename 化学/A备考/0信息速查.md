# 气密性
## 水柱法
对于带长颈漏斗和导气管的装置，先夹紧导气管上的橡皮管，再从长颈漏斗注水，使漏斗下端浸入液面，并使漏斗内形成高于容器液面的水柱。停止注水后，若液面差在观察时间内保持稳定，说明装置气密性良好。

水封和夹闭使装置内部形成受限气体空间。水柱产生的压强差会随漏气而减小，因此观察液面差能否保持，比只看某一处水面是否下降更明确。
## 气泡法
对于试管与导管组成的装置，将导管末端浸入水中，用手握住试管外壁。内部气体受热膨胀，若导管口出现气泡，移开手冷却后又有水进入导管形成一小段水柱，且水柱能保持，可据此判断装置气密性良好。操作前须使各接口连接妥当。
## 推拉注射法
对于带长颈漏斗并接有注射器的装置，使漏斗下端浸入液面，再缓慢拉动注射器活塞。内部气压降低，外界空气可从漏斗下端进入，产生气泡。观察时需结合装置结构，确认除这一入口之外各处均已密闭；漏斗下端未浸入液面时，这一判据不适用。

# 空气的组成
以下为近地面干燥空气的近似体积分数，水蒸气含量另随环境变化。

- 氮气约78%。
- 氧气约21%。
- 氩约0.93%，另有少量其他稀有气体。
- 二氧化碳约0.04%，其含量随时间和地点变化。
- 其余为痕量气体；上述数值经过取整，不用于精确求和。

资料参考：[NOAA 大气组成](https://www.noaa.gov/jetstream/atmosphere)。
