#化学备考 
# 化合物
能用化学式表达的都是化合物。
# 化合价
化合物均有固定的组成，即形成化合物的元素有固定的原子个数比。
如 $HCl$ 的原子个数比是1：1，$H_{2}O$ 是2：1，$CO_{2}$ 是1：2，$Fe_{2}O_{3}$ 是2：3。
不同元素相互结合时，其原子个数比并不都相同，反映这个比值的就是元素的化合价。化合价是元素的一种性质，它用来确定元素原子之间相互结合的数量关系，通常称为元素的化合价，而不能称为原子或某物质的化合价。
## 化合价的表示方法
表示化合物中各元素或原子团（离子）的化合价时，通常是在元素符号或原子团的正上方用+n 或-n 表示。
哪怕数值为一时，也不能省略。
## 常见元素的化合价
- **一价**：氢（$H^{+}$，与非金属结合时）、氯（$Cl^{-}$）、钾（$K^{+}$）、钠（$Na^{+}$）、银（$Ag^{+}$）、氟（$F^{-}$）
- **二价**：氧（$O^{-2}$，在 $H_{2}O_{2}$ 中显-1）、钙（$Ca^{+2}$）、镁（$Mg^{+2}$）、锌（$Zn^{+2}$）、铜（$Cu^{+2}$）、汞（$Hg^{+2}$）
- **三价**：铝（$Al^{+3}$）
- **四价**：硅（$Si^{+4}$）、碳（$C^{+4}$）
- **五价**：磷（$P^{5+}$）
- **多变价**：铁（$Fe^{+2}$，$Fe^{+3}$）、硫（$S^{-2}$，$S^{+4}$，$S^{+6}$）、碳（$C^{+2}$，$C^{+4}$）
- 单质价态为0。
### 常见原子团的化合价
- **硝酸根**：$NO_{3}^{⁻}$（-1）
- **氢氧根**：$OH^{-}$（-1）
- **硫酸根**：$SO_{4}^{2-}$（-2）
- **碳酸根**：$CO_{3}^{2-}$（-2）
- **铵根**：$NH_{4}^{+}$（+1）
## 化合价的一般规律
1. 化合价有正价和负价
2. 金属与非金属元素化合时，金属元素显正价，非金属元素显负价，如 $NaCl$，Na+1，Cl-1。
3. 一些元素在不同的物质中可显示不同的化合价，如 $NO$ 中，因为 O 的化合价代数-2，N+2；$NO_{2}$ 时，因为 $O_{2}$ 的化合价代数-4，N+4。
4. 同一种元素在同一化合物中的化合价也可能不相同，如 $NH_{4}NO_{3}$，第一个 N-3，第二个 N+5。
5. 在化合物里，各元素正负化合价的代数和为0。
   在原子团中，则是代数和时原子团所带的电荷数相同。
   元素的化合价是元素的原子在形成化合物时表现出来的一种性质，因此单质里，元素的化合价为0。
6. 书写化学式时，一般按正价元素在左，负价元素在右的顺序。
   偶有特殊，如 $NH_{3}$（N-3），$CH_{4}$ （C-4）

### 根据化学式计算某元素的化合价
化合物中各元素正负化合价的代数和等于0是计算依据，**一般根据无变价元素的化合价推求有变价元素的化合价**。
比如 $MgCl_{2}$，设氯元素为 x，2x+2=0，氯元素-1。

### 根据化合价推求化合物的化学式
依据化合物中各元素正负化合价的代数和为0的这条规律，确定元素的原子个数比。
e.g 如某种磷的氧化物中，磷+5，氧-2。
1. 写出组成化合物的两种元素的符号，正价写左边，负价写右边：P:O
2. 求两种元素正负化合价绝对值的最小公倍数：$5 \times 2=10$
3. 求各原子的原子数：$\frac{最小公倍数}{正价数(或负价数)}$，$P=\frac{10}{5}=2$ ，$O=\frac{10}{2}=5$
4. 得化学式 $P_{2}O_{5}$。
5. 检验代数和。

还可以用十字交叉法。
e.g +6价硫的氧化物。
1. 排序，S：O
2. 标价，S+6，O-2
3. 约数，S+3，O-1
4. 交叉，将化合价的绝对值交叉到零一元素的右下角，即把3写到氧原子右下角，1写在硫原子右下角，得出 $SO_{3}$
5. 对于原子团，应看作一个整体。出现多个原子团时，加上括号，该法仍适用。


化合价还可以反过来判断、设化学式。
