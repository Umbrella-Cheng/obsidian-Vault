#化学 #物质组成 #碱
# 碱的定义
在水溶液的阿伦尼乌斯描述中，**碱**是能增加氢氧根离子浓度的物质。金属氢氧化物是典型实例；氨也可通过与水反应增加 $\ce{OH-}$。

布朗斯特–劳里理论把碱定义为质子受体，与[[酸]]作为质子供体相对应。

e.g. $\ce{NH3 + H2O <=> NH4+ + OH-}$ 中，氨接受水提供的质子；水在这项反应中作为酸。结合水与氯化氢的反应，可看到同一种物质的酸碱角色由具体质子转移决定。
# 碱的分类
## 溶解度
常见金属氢氧化物可按水中溶解度分为易溶、微溶和难溶。溶解度描述进入溶液的程度，碱的强弱则描述有关平衡中的反应倾向，二者需要分别判断。
## 电离数
对常见金属氢氧化物，可以按每个化学式单位对应的氢氧根数讨论一元、二元等类别。e.g. $\ce{NaOH}$ 对应一个，$\ce{Ca(OH)2}$ 对应两个。离子晶体中的这些单位用组成式表示，不必假定存在独立分子。

> [!note] 电离数是什么
> 这里按化学式与反应方式判断可中和的数量，和[[酸#^37edb1|酸的元数]]有相通之处。采用质子受体定义后，还需直接考察可接受质子的位置，不能把所有碱都按式中 $\ce{OH}$ 的数目分类。
## 碱的强弱
给定溶剂和条件下，碱接受质子的倾向可用相应平衡描述。氨与水的反应仅部分进行，是典型弱碱；比较碱性强弱应明确反应体系，不能只看溶液浓度或溶解度。
# 碱的通性
1. 碱性溶液使合适的指示剂改变颜色，e.g. 石蕊变蓝，酚酞在相应变色范围内呈粉红至红色。
2. 碱与酸发生质子转移。氢氧根与水合氢离子结合生成水；氨与氯化氢则可形成铵盐。
3. 碱可与适当的[[酸性氧化物]]反应，产物取决于配比，e.g. 碱足量时 $\ce{CO2 + 2OH- -> CO3^2- + H2O}$。
4. 碱与盐的反应需检查沉淀或质子转移等条件。e.g. $\ce{Cu^2+ + 2OH- -> Cu(OH)2 v}$；加热铵盐与强碱可使氨逸出，相关质子转移为 $\ce{NH4+ + OH- <=> NH3 + H2O}$。所谓“强碱制弱碱”须结合平衡与产物移出解释，不能直接替代反应条件。 ^853fff
