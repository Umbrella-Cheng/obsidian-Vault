# 碱性氧化物的概念
**碱性氧化物**是在通常的酸碱反应分类中，能与[[酸]]反应生成盐和水、相关元素氧化数保持不变的[[氧化物#成盐氧化物|成盐氧化物]]。[[两性氧化物]]同时表现对酸与碱的反应性，另作一类讨论。

常见碱性氧化物包括 $\ce{Na2O}$、$\ce{CaO}$、$\ce{CuO}$。金属氧化物还可能表现两性或酸性，需结合其结构、氧化态及反应判断。
## 碱性氧化物的通性
1. 与适当的酸反应生成盐和水。

   e.g. $\ce{CuO + 2HCl -> CuCl2 + H2O}$，铜在前后均为+2。
2. 与适当的[[酸性氧化物]]反应生成盐。

   e.g. $\ce{CaO + CO2 -> CaCO3}$。
3. 部分碱性氧化物与水反应生成氢氧化物。

   e.g. $\ce{CaO + H2O -> Ca(OH)2}$。这是一项化学反应；是否能与水反应，需要考察结构、反应条件和动力学。$\ce{CuO}$ 在通常条件下不与水直接生成 $\ce{Cu(OH)2}$，却可用与酸的反应确定其碱性。参照[[酸性氧化物#^1aa94d]]，可分别检验“有对应酸碱”和“能否直接与水反应”。
### 通性的利用
判断碱性氧化物时，可以先选通常的非氧化性酸，检验是否发生保持相关元素氧化数的酸碱转化。若反应同时涉及氧化还原或配位过程，应进一步区分实际机制。

过氧化物、超氧化物中的含氧离子具有不同的结构和氧化态，在常见无机分类中另行讨论，不能只凭“能与酸反应”套用普通氧化物的类别。
