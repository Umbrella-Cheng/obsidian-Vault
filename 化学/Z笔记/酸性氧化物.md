# 酸性氧化物的概念
**酸性氧化物**是在通常的酸碱反应分类中，能与[[碱]]反应生成盐和水、相关元素氧化数保持不变的[[氧化物#成盐氧化物|成盐氧化物]]。识别时要考察反应中表现的酸性，而非仅看生成物中是否出现盐；[[两性氧化物]]另作一类讨论。

常见酸性氧化物包括 $\ce{CO2}$、$\ce{SO3}$、$\ce{SiO2}$；部分高氧化态金属氧化物也表现酸性，如 $\ce{Mn2O7}$。由此可见，金属或非金属分类只能提供线索，还需要具体反应证据。
## 酸性氧化物的通性
1. 与适当的碱反应生成盐和水，相关元素氧化数不变。

   e.g. $\ce{CO2 + 2NaOH -> Na2CO3 + H2O}$，适用于碱足量的情形。二氧化碳过量时，还需考虑碳酸氢盐。
2. 与适当的[[碱性氧化物]]反应生成盐，通常需要适宜温度等条件。

   e.g. $\ce{CaO + SiO2 ->[高温] CaSiO3}$。
3. 能直接与水反应的酸性氧化物，可生成对应的酸。

   e.g. $\ce{SO3 + H2O -> H2SO4}$。$\ce{SiO2}$ 在通常条件下不直接与水反应；其晶体网络的结构与反应动力学，使“存在对应含氧酸”不足以推出“加水就生成酸”。 ^1aa94d

二氧化碳与碱的配比，可以把总反应拆成两个连续的净变化来理解：

$$
\ce{CO2 + OH- -> HCO3-},
$$

$$
\ce{HCO3- + OH- -> CO3^2- + H2O}.
$$

第一步消耗一个氢氧根，形成仍有可转移氢的碳酸氢根；碱继续足量时，第二步再接受一个质子。将两式相加并约去中间的碳酸氢根，正好得到 $\ce{CO2 + 2OH- -> CO3^2- + H2O}$。这是解释总体计量的反应分解，不把它等同于已经确定的全部基元反应步骤。

因此先辨认产物所处的酸碱状态，再核对原子和电荷，比先背一个固定配比更有根据。

### 通性的利用
从反应反推分类时，应检查反应物、产物和氧化数。e.g. $\ce{CO2}$ 与碱反应时碳仍为+4，符合酸碱转化；$\ce{NO2}$ 与碱反应却可生成亚硝酸盐和硝酸盐，氮由+4变为+3与+5，这是歧化过程，不能据此将它判为酸性氧化物。

酸性、碱性和两性氧化物的常见分类主要用于相应的普通氧化物。过氧化物含氧氧键，氧通常为−1，需单独讨论其酸碱和氧化还原性质；“氧化数不同于−2”本身不构成关于稳定性的充分判断。
