# 一元二次方程的定义
一元指的是方程只有一个未知数 x，二次指的是 x 的最高次数为2。
一元二次方程的一般式为 $ax^2+bx+c=0（a≠0）$，很多对于它的计算本质上都是对一般式的不同变式运用。
满足一元二次方程成立的未知数 x 的值被称为该方程的解/根。
一元二次方程通常有两个根或者没有实数根根，用 $x_{1}$ 和 $x_{2}$ 来分别表示两个根。
# 一元二次方程的解法
解法无高低好坏之分，条条大路通罗马。
## 配方法
配方法是解一元二次方程最基础的办法之一，脱胎于[[因式分解]]中的完全平方公式。
其核心逻辑是由多方概念组成的，这也使它无论在一元二次方程还是二次函数的应用，甚至更广的层面是同时能具有代数意义和几何意义的。
本质上，配方法是通过把值整体化，令方程设计未知数的项变为整体 x，令整体 x 等于的实数 y，即 $x^2=y$，来解出 x 的实数值。

设 $x^2=p$，分类讨论 x 的取值情况：
1，$p>0$，$x=±\sqrt{p}，x_{1}=\sqrt{p  }，x_{2}=-\sqrt{p  }$
2，$p=0$，$x_{1}=x_{2}=0$
3，$p<0$，无实数根。

通过配方，即令 $x^2+bx$ 的和进行平方 $(x+\frac{b}{2})^2$，保持未知数 x 参与的数值不变的同时，增减多出或少于的常数项，得出差值 p。进而使配方前后两个式子相等，便可根据 $x^2=p$ 快速解出方程的根。简单点来说就是凑 $x^2$ 并让它等于p。
e.g $x^2+6x+4=0，(x+3)^2-9+4=0，(x+3)^2-5=0，(x+3)^2=5$
如果要对配方法进行分析，那么就可以从 x 的平方性质入手。回到最初的 $x^2=p$，这就是一元二次方程的基础，把复杂的方程式变为最简易的等式求值，一步求出 $\sqrt{ p }和-\sqrt{ p }$ 对应的两个实数根。

一般而言，出于方便的目的，$x^2$ 系数会保持1，如果系数不为1，那么可以对式子进行通分。
e.g $2x^2-3x+1=0，x^2-\frac{3}{2}x+\frac{1}{2}=0$
但这一步骤不一定要一开始就进行，根据实际情况而定。比如可以保留系数直到最后剩下 $ax^2=p$，然后 $x^2=\frac{p}{a}$ 就行。
## 公式法
公式法所用的公式又叫求根公式，本身就是一元二次方程的一般式 $ax^2±bx±c=o$ 进行配方法得出的，只是保留了未知数字母，可代入任意数。
对于任意的一个一元二次方程，可用 $x=\frac{-b±\sqrt{b^2-4ac}}{2a}$ 来求值。

通过配方法，一元二次方程的一般式得出 $(x+\frac{b}{2a})^2=\frac{b^2-4ac}{4a^2}$，由于不能确定右边的 $\frac{b^2-4ac}{4a^2}$ 是否成立，需要进行分类讨论：
1，$b^2-4ac＞0$，则求根公式成立，分别对 $x_{1}$$x_2$ 进行代入计算。
2，$b^2-4ac=0$，则 $x=x_{1}=x_{2}=-\frac{2b}{a}$
3，$b^2-4ac＜0$，则该式不成立，无实数根。
通过 $b^2-4ac$ 又可以迅速判断一个一元二次方程有无实数根，所以 $b^2-4ac$ 又被称为判别式/Δ（德尔塔），$Δ=b^2-4ac$。

在求值时，如果 b 为偶数，还可以将其设为2b'，方便公式中的代入。类似思维也如此。
## 因式分解法
因式分解法应该是较为简单的解法，其核心就在因式分解上。
e.g $10x-4.9x^2=0,x(10-4.9x)=0$，因为0×0才等于0，所以 x 和10-4.9x 中各有一个为0，$x_{1=0}$，$x_2=\frac{100}{49}$
e.g $x^2+3x-4=0$ 可以通过十字相乘法得出 $(x+4)(x-1)=0$，$x_{1}=-4$，$x_{2}=1$

## 根与系数的关系（韦达定理）
$x_{1}+x_{2}=-\frac{b}{a}$
$x_{1}x_{2}=\frac{c}{a}$
这是通过对求根公式的推导得出的根与系数的关系，又称**韦达定理**。

韦达定理虽好用，但是实际运用中要学会举一反三，反推根与系数的关系，才能正确运用。
e.g $a^2-a-6=0$ 和 $b^2-b-6=0$，因为平方的特殊性不能简单地就划 $a=b$。在题目给出 $a≠b$ 的情况下可以直接代入 $x^2-x-6=0$，从而得出 $a_{1}=x_{1}=b_{2},b_{1}=x_{2}=a_{2}$。如果没有给出，则根据实际情况选择分析方向。比如构建起一个新的一元二次方程并使它成立以观察题目条件等等。
