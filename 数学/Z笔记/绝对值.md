#数学
#代数/数与式
绝对值是指一个数在数轴上所对应点到原点的距离，用 $\lvert x\rvert$ 表示。
# 绝对值的定义
绝对值具有两种定义，代数定义及几何定义。代数定义来源于对几何定义的提炼，而几何定义来源于对代数定义的可视化。
所以在探讨数学中的绝对值时，需要发挥数形结合思想，善于选择合适的定义来进行研究任务。
## 绝对值的代数定义
绝对值的代数意义，是指对于绝对值 x 的分类讨论。  
当 x 大于零的时候，绝对值就等于 x 的本身；当 x 等于零的时候，绝对值等于0，就还是 x 的本身；当 x 小于0的时候，绝对值就会等于它的相反数，即$-x$。
即正数和0的绝对值是它本身，负数的绝对值是它的相反数。
当 $x> 0$ 时，$x=x$
当 $x=0$ 时，$x=0=x$
当 $x< 0$ 时，$x=-x$

## 绝对值的几何定义
绝对值的几何定义，是指对于数轴上点 X 和原点之间距离 $\lvert a\rvert$ 的表达。

# 绝对值的应用
## 零点分段
在研究未知数的取值时，常常会涉及到区间。因为区间距离就是两点之间的距离，且作为标量，区间距离不带正负号。为了方便、快捷地得出这些区间，就将绝对值的性质迁移，应用在解未知数中。
零点分段，就是基于绝对值的几何意义，映射、迁移到代数意义并结合应用的思路。
### 零点
零点，就是令数轴上的两点重合时的值，或者看作函数值为0时的 x 取值，但此处重点在于研究绝对值，而数学描述的本质都是同一种内容的不同面，纠结于形式是无意义的。
这是应用了绝对值 $\ge$ 0的性质，取绝对值=0时的特殊情况，得出在该情况下 x 的取值。
e.g 求 $2x-3$ 的 x 取值时，可以使 $2x-3=0$，此时原式具有等量关系，变为方程，解得 $x=1.5$，即原式在 $2x-3=0$ 时的 x 值，同时，2x也是常数值3。
基于零点的定义与性质，方程的解法又由此迁移出去，在两边存在等量关系的情况下，优先让一侧为0，就是这个原因。
#### 零点与方程
实际上，零点与方程的关系要更为紧密。
如果把方程看成存在于数轴上的距离，方程 $2x-3=1$ 时，只看两端，连续的距离就是 $\lvert 2x-3-1\rvert$。因为 x 是未知数，不能主动设定取值，而单独的绝对值因为不存在等量关系，同样不能解开。这时设该绝对值为0，实际上就能获得一个新的等量关系。
已知 $\lvert 2x-4\rvert$ 是点2x 到点4之间的距离，令该绝对值为0，两点重合， $2x=4$，$x=2$，就是这样。

### 分段
分段，是对零点的进一步扩展，适用于求多个未知数取值的情况。
一般来说，题目中存在几个不相同的绝对值时，零点数量等于绝对值数量。
这么说可能不太详细，参见下图。数轴上存在 A、B、C 三点，假设它们每一点都有对应的1个未知数 x 与之重合，就会同时存在3个零点。
![[Pasted image 20260516132638.png]]
两点之间存在一条线段，所以 BC 内存在 AB、AC 两线段，已知 $\lvert B+x\rvert=\lvert A+x\rvert=\lvert C+x\rvert=0$，又知 $B=-3$， $A=-1$，$C=0$，则 x 同时存在3个取值分别满足对应值。
如果将 B、C 两点取消，使 AB、AC 成为射线，则 x 存在 $x=1$、$x\le 1$ 、$x\ge 1$ 这三类取值。
于是就得到了分段的应用思路。
#### 分段与方程的延伸思考
分段是零点的延申，如果说零点关联着一元一次方程，分段就关联着多次方程。
无论是二次、三次、四次还是更高次的方程，设一条直线，它们的解都会交于直线。这是因为同一种情况下，一定会同时出现方程解，无论这条线取在什么高度都不改变这个判断，因为它只是代表了发生在同一种情况下的所有可能，就好比一元四次方程，永远会有四个复数解出现在同一水平线（y 值）上。
那么基于此，分段，就是在忽略不与数轴相交的图像的情况下，孤立的求解。但在一些特定情况下，孤立地求解，反而能透过现象，直击本质。
#### 分段与不等式的延伸思考
分段在不等式上的运用，可以看作是一个相交在所有数轴点上的特殊方程，需要让每个点都成为零点，那么每个点的未知数取值都不相等，构成一个连续不等式。
这时候只需要锚定原式存在的零点，并高亮零点，将其余点变暗，然后计算、讨论每个高亮点左右存在情况即可。
