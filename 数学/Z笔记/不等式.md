# 不等式的定义 
用符号“>”“<”表示大小关系、诸如 $a>b$ 的式子叫作不等式。用“≠”表示不等关系的式子也是不等式。其中，两边的解析式的公共定义域称为不等式的定义域。

# 不等式的性质
## 不等式的保序变换
不等式建立在定义了序关系的数集上，这种整体的大小关系结构在数学上称为序结构。对于实数而言，这种序结构表现为数轴上的左右关系，即两个元素之间可以按照大小进行比较。
不等式中的变换具有保序性，所谓保序，是指经过某种变换后，两个量之间的序关系仍保持。

对于任意满足 $a>b$ 的 a、b，若某变换 $f$ 满足 $f(a)>f(b)$，则该变换保持了 a、b 之间的序关系。
### 变换 $f$
变换 $f$ 有诸如以下几种形式。
#### 平移
有 $a>b$，a、b 同时加上 c，无论 c 的正负，都有 $a+c>b+c$，因为 $(a+c)-(b+c)=a-b>0$，所以加法保持 $a>b$ 的序关系。
#### 比例缩放
有 $a>b$，a、b 同时乘上 c。
- $c>0$ 时，有 $ac>bc$。因为 $c(a-b)>0$，正负性不变，所以正数乘法保持 $a>b$ 的序关系，在该关系基础上，$a-b$ 的差值变换为原来的 c 倍。
- $c<0$ 时，有 $ac<bc$。因为 $c(a-b)<0$，正负性改变，所以负数乘法反转 $a>b$ 的序关系，在该关系基础上，$a-b$ 的差值变换为原来的 $|c|$  倍。
- $c=0$ 时，有 $ac=bc=0$，此时序关系丢失。
#### 幂函数
有 $a>b$，引入 n，使 a、b 分别乘以 n 次，有 $a^n>b^n$ ，保持 $a>b$ 的序关系。
#### 开方
有 $a>b$，引入 n，使 a、b 分别除以 n 次，有 $\sqrt[n]{a}>\sqrt[n]{b  }$，保持 $a>b$ 的序关系，且 $n\in Z$ ，$n\ge 2$。
#### 变换 $f$ 的变换应用
在实际运用中，对不等式的两边分别各施加一个不同的变换 $f$ 的时候，基于变换 $f$ 的形式，可以运用分类讨论的思路解决问题。
有 $a>b$，$c>d$ 时，对于 $a+c$ 和 $b+d$ 的关系，因为 a、c 分别大于 b、d，则 $a+c>b+d$
而对于 $a>b$，$c<d$ 时，应考虑是否  $d-c\le a-b$，若成立，才可以说 $a+c>b+d$，反之亦然。
通过分别讨论原式与新增的两个变换 $f$ 的关系，就可以解决类似的复合问题。

整式不等式是指不等式的两端均为整式的有理不等式，其未知数不在分母上，含有 n 个未知数且两端整式最高次数为 r 时称为 n 元 r 次不等式。

### 高次不等式
从[[#一元二次不等式]]的思路延申：是否可以限定一个高次函数来代表高次不等式呢？
显然，是可以的。

假设存在一个高次函数来代表一个高次不等式，比如用 $f(x)=x^6+c$ 来代表 $x^6+c<0$，对 $x^6+c$ 进行拆分，变为 $(x+a)(x+b)(x+c)\dots$ 这样的形式，使用穿根法，或者说一种分段的思路就可以解决高次不等式的相关问题。
先令 $f(x)=0$，则可得 $x_{1}=-a,x_{2}=-b,x_{3}=-c\dots$
将 $x_{1},x_{2},x_{3}\dots$ 分别标注在 y=0时的 x 轴上，大致如图 ![[Pasted image 20260821085611.png]]
此时，有两种图像的可能。
![[Pasted image 20260821090045.png]] 或 ![[Pasted image 20260821090109.png]]
为了判断具体图像，可以给 x 设定一个在两点之间的值，取整方便计算。
比如设定 x=100，x 在 $x_{3}$ 右侧。计算 $(100+a)(100+b)(100+c)$ 的正负，若为正数，则图像为图一，$x_{3}$ 右侧的图像走向为 y 随着 x 的增大而增大。若为负数，则图像为图二，$x_{3}$ 右侧的图像走向为 y 随着 x 的增大而减小。
以此类推，分别求出 $x_{1},x_{2},x_{3}\dots$ 左右侧的走向。
而判断完图像，基本也就解决了该问题。根据具体问题要求，取 y 值正或负时的 x 取值区间即可。

e.g $(x-1)^2(x+2)(3x-1)>0$
令 $x=100>1$ 时，三个括号均为正数，所以在 x 取值的100~1区间内， y 大于0，x>1区间的 y 大于0。
再令 $x=\frac{2}{3}<1$，发现 $(3x-1)>0$，所以在 x 取值的1~ $\frac{1}{3}$ 区间的 y 大于0。
再令 $x=-1<\frac{1}{3}$，发现 $(3x-1)<0$，所以在 x 取值的 $\frac{1}{3}到-2$ 区间的 y 小于0。
最后令 $x=-3<-2$，发现两项为负数，负负得正，所以在 x 取值的 x＜-2区间的 y 大于0。
得出的图示如下：![[Pasted image 20260113093107 1.png|448]]
由此得， $(x-1)^2(x+2)(3x-1)>0$ 的解集是 $x<-2$ 或 $x>-\frac{1}{3}$ 。

## 绝对值不等式
绝对值不等式的解法可以利用[[绝对值]]的性质，即绝对值是离原点的距离这一点入手。

已知 $|x+b|>c$，则 x 的取值区间需满足 $x+b>c$ 、 $x+b<-c$。若要求是小于 c，则反之亦然。
若 c 同样为绝对值，则使 $|x+b|>|c|$ 变为 $(x+b)^2>c^2$，即可一次求出 x 的取值区间。若不然，则分类讨论 c>0和 c<0的情况。

通过数形结合也可以验证上述思路。

## 基本不等式
基本不等式，又称均值不等式。是数学中一个非常重要的“恒不等式”，描述了对于任意两个正数，其几何平均值与算术平均值之间的关系。
### 基本不等式的二元情形
对于任意正数 a、b，有基本不等式 $\frac{a+b}{2}>\sqrt{ ab }$（当且仅当 a=b 时等号成立）。
其中，$\frac{{a+b}}{2}$ 被称作两个正数的算术平均值，$\sqrt{ ab }$ 被称作两个正数的几何平均值。

### 和积式
和积式是对基本不等式的二元情形的变形，式子为
$$\Box+\triangle \geq 2\sqrt{\Box \triangle}$$
### 非齐次式
非齐次式，顾名思义，就是各项次数不一的式子。
其特点十分明显，即对于底数相同的式子，可以先将其转化为和积式，再根据和积式化简为最简形式。
e.g 对于 $2x+\frac{1}{x}$（$x>0$），可转化为 $2x+\frac{1}{x}\ge 2\sqrt{ 2x\times \frac{1}{x} }$ 的形式，化简得 $2x+\frac{1}{x}\ge 2\sqrt{ 2 }$。

> [!note] 思路辨析
> 非齐次式本质上是对不等式的辨别、验证、转化，得出更简明的集合范围的代数式表达。对于较易误导或冗长的式子，它起到的作用是快捷的。
### 齐次式
齐次式，即分子分母每项次数都相同的式子。
针对它的化简，同样将其先转化为和积式，再根据和积式化简为最简形式。

对于齐次式，常见的有两种情况。
#### 分子复杂的齐次式
对于分子复杂的齐次式，可以采用**拆分子**的思路。
对于形如 $\frac{{a+b}}{a}+\frac{{a+b}}{b}$ 的形式，可以将原式拆为 $\frac{a}{a}+\frac{b}{a}+\frac{a}{b}+\frac{b}{b}=2+\frac{b}{a}+\frac{a}{b}$ 的形式，单独求 $\frac{b}{a}+\frac{a}{b}\ge 2\sqrt{ \frac{b}{a}\times \frac{a}{b} }\ge 2$，原式为 $2+2=4$.
#### 分母复杂的齐次式
对于分母复杂的齐次式，可以采用**换元**的思路。
对于形如 $\frac{a}{a+b}+\frac{b}{a+2b}$ 的式子，设 $a+b=m$，$a+2b=n$，根据二元一次方程组的简化思路，求得 $a=m-b=2n-m$，$b=m-n$，则原式变形为 $\frac{{2n-m}}{m}+\frac{{m-n}}{n}$，再采取[[#分子复杂的齐次式]]的解法，即可求原式为 $\frac{2n}{m}+\frac{m}{n}+2\ge 2\sqrt{ n }-2$
