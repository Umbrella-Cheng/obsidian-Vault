#生物 #细胞

# 细胞器的概念

**细胞器**（Organelle）是细胞内部具有相对特定结构与功能的组成单位。
狭义上常指具有膜包围的细胞内区室；
广义上也包括核糖体、中心体等无膜结构。不
同教材对细胞核是否归入细胞器的处理并不完全一致，本文将其作为相关的独立细胞结构讨论。

# 细胞内部的区室化

真核细胞通过生物膜形成多个具有**不同化学环境**的区室，使相互关联或可能互相干扰的反应在空间上得到组织。
区室化有助于维持离子浓度、酸碱度及酶和底物的局部分布。细胞器之间并非彼此孤立：物质、能量与信息通过囊泡运输、膜接触位点和细胞内信号网络相互联系。

# 主要结构及功能

| 结构         | 主要功能                             |
| ---------- | -------------------------------- |
| [[细胞核]]    | 储存与组织核基因组，参与转录调控，是调控中心           |
| [[核糖体]]    | 按信，使 RNA 信息合成多肽，进而与其他细胞器协作合成分泌蛋白 |
| [[内质网]]    | 分泌及膜蛋白合成、脂质合成与钙离子储存              |
| [[高尔基体]]   | 蛋白质和脂质的修饰、分选与运输                  |
| [[线粒体]]    | 多种代谢反应及氧化磷酸化，有氧呼吸的主要场所和供能区       |
| [[叶绿体]]    | 在植物和藻类细胞中进行光合作用                  |
| [[溶酶体]]    | 酸性环境中的大分子降解与物质回收                 |
| [[过氧化物酶体]] | 特定氧化代谢及过氧化氢处理                    |
| [[液泡]]     | 储存、渗透调节与部分降解过程                   |
| [[中心体]]    | 动物细胞中常见的微管组织中心                   |

原核细胞通常没有由膜包围的细胞核以及典型的内膜系统，其生物膜系统只有细胞膜。但仍具有核糖体，并可具有多样化的细胞内组织结构。
真核细胞之间也存在差异：叶绿体并非所有植物组织细胞都有，成熟哺乳动物红细胞通常失去细胞核和多数细胞器。

# 细胞器之间的协作

分泌蛋白通常在附着于粗面内质网的核糖体上合成，进入内质网后折叠和加工，再经运输囊泡到达高尔基体，进一步分选至质膜、胞外或其他目的地。此过程需要膜交通与能量供应，并与[[细胞膜]]的胞吐过程相联系。

线粒体、叶绿体和过氧化物酶体之间还存在代谢物交换。理解细胞器时，既要认识每一种结构的独特机制，也要把它们置于细胞整体的物质与能量流动之中。
